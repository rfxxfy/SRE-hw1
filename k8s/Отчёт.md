# Отчёт: запуск приложения в Minikube

## Приложение

«Список задач» состоит из веб-сервера на Flask/Gunicorn и PostgreSQL. Образ приложения собирается из `Dockerfile` как `taskboard:k8s-v1`. PostgreSQL запускается из официального образа `postgres:16-alpine`. Фронтенд содержится в образе приложения и обращается к REST API по HTTP.

## Абстракции Kubernetes

| Абстракция | Применение |
| --- | --- |
| Deployment | `taskboard-web` запускает веб-приложение и масштабируется с одной до трёх реплик. `taskboard-postgres` запускает одну реплику PostgreSQL со стратегией `Recreate`. |
| Pod | Создаются контроллерами Deployment и Job; каждый Pod приложения работает без локального постоянного состояния. |
| Service | `taskboard-web` распределяет HTTP-запросы между готовыми репликами. `taskboard-postgres` даёт БД постоянное DNS-имя внутри кластера. |
| PersistentVolumeClaim | `taskboard-postgres-data` хранит данные БД при перезапуске Pod. |
| Secret | `taskboard-db` передаёт пароль PostgreSQL в контейнеры БД, миграции и веб-сервера. В манифесте находится только учебный пароль. |
| Job | `taskboard-migrate` разово создаёт таблицу задач командой `python -m app.migrate`. |
| Probes | PostgreSQL проверяется через `pg_isready`; веб-сервер — через `/healthz` и `/readyz`. Готовность веб-сервера требует доступной таблицы задач. |

## Взаимодействие сервисов

Браузер подключается к `service/taskboard-web` через `kubectl port-forward`. Сервис направляет запрос на готовый Pod веб-приложения. Бэкенд обращается к `service/taskboard-postgres` по внутреннему DNS имени `taskboard-postgres`; пароль поступает из Secret. PostgreSQL хранит записи в PVC. Job миграции использует тот же образ приложения и то же подключение к БД. После масштабирования все веб-реплики используют общую БД, поэтому данные видны с любой реплики.

## Проверка

Перед развёртыванием команды `kubectl run`, `wait`, `get`, `logs`, `describe` и `delete` были проверены на временном Pod. Команды запуска, просмотра Pod, масштабирования и доступа к UI приведены в `README.md`. В скринкасте `Демонстрация.mov` показаны `kubectl apply`, список Pod, `kubectl scale` и действия в интерфейсе приложения.
